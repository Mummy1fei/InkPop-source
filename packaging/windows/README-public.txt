InkPop · Windows x64

把整个压缩包解压到一个新文件夹，双击 InkPop.exe 启动。
InkPop-cli.exe 是命令行工具。图像识别所需的模型和运行库随包提供。

新设备首次运行时使用默认设置。之后的首选项、笔刷和最近文件保存在当前 Windows 用户的应用数据目录。升级时使用同一个 Windows 用户即可继续使用已有设置。

普通混合画笔使用 InkPop 的拾色与带色算法。笔刷设置中的“模拟绘画颜料”使用 InkPop 自研的颜料混合模型，直接在同一个程序中启用。

开源软件、模型与运行库的署名和许可见 NOTICE、ATTRIBUTION.md、models 和 assets 下的许可文件。
