# InkPop

中文 · [English](README.en.md)

InkPop 基于开源项目 [PhotoCraft v0.5.0](https://github.com/storytold/photocraft/releases/tag/v0.5.0) 开发。该版本发布于 2026 年 10 月 8 日，我们于次日开始开发 InkPop。

InkPop 面向 Windows，广泛覆盖 Photoshop 常用的绘画和修图流程。从画笔起稿、选区和图层合成，到 Camera Raw 调色和 PSD 编辑，熟悉 PS 的用户可以沿用自己的操作习惯。

**带上熟悉的笔刷。** 导入 Photoshop 的 ABR 笔刷和 TPL 绘画工具预设时，受支持的采样笔尖、纹理、双笔尖、间距和混合参数可随预设载入。大型预设的选择更顺畅，使用细长笔尖时收笔等待更短。

**混合画笔。** 我们用同一支水油彩预设对照 Photoshop 的实际笔迹，改善了连续运笔时的拾色、带色和回涂，笔尾的颜色过渡也更自然。

**自定义皮肤和工作区。** 「工作室（浅色）」主题提供四套配色。你可以单独调整标题栏、菜单和面板的颜色，导出配色分享，也可以拆分、停靠面板，把常用布局命名保存。

## Windows 便携版

在本仓库的 Releases 页面下载 Windows x64 便携 ZIP，完整解压后双击 InkPop.exe。首次使用手绘板时，请在手绘板驱动的应用程序设置中手动添加该 InkPop.exe，再启动软件测试压感。
